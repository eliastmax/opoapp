# CONTENT-FACTORY.7 · Canonical Mastery Family Resolver

Factory.7 adds a semantic mastery-family layer without weakening the Factory.6 anti-overmerge guard.

## Three levels

1. **Question facet** — V2 `concepto`, `objetivo_aprendizaje`, `perspectiva`, `tipo_trampa` and `nivel_pedagogico`. These describe the local way a question probes knowledge and are not canonical mastery identity.
2. **Source scope** — unit, section, article, span and page context. It bounds the candidate space but shared structure does not prove mastery identity.
3. **Mastery concept** — a stable teachable, recallable and testable knowledge unit. Different facets belong together when they evaluate the same teachable nucleus; materially additional canonical knowledge requires a split.

## Pipeline

`Canonical source + V2 bank -> concept_family_resolution packets -> semantic operation -> deterministic validation -> SemanticTopicDraft -> existing Fast Pipeline`

Packets are generated by Factory per source-backed unit and contain canonical text/spans plus local V2 facets and optional raw lexical hints. They contain no manual mastery map.

The semantic operation returns structured families with `provisionalFamilyId`, title, mastery statement, question codes, source refs, included facets, nearby-family exclusion reason, confidence and rationale. Factory then allocates deterministic concept codes and validates exactly-one-primary, zero loss, source traceability, unit coherence, no source leakage and optional approved anchors.

Factory.6 complete-link remains available as an anti-overmerge/raw diagnostic; it is not the final greenfield family generator.

## Boundary guards

Semantic operations may return material overmerge or undermerge guards only with explicit family IDs, question codes, explanation and a concrete split/merge proposal. Concept/question ratios are diagnostic signals only and never create a boundary exception by themselves.

## Approved replay

When an approved V4 structure is supplied, Factory.7 performs approved replay and executes zero family-resolution operations. Approved T13/T18/T19/T20 structures are therefore not reinterpreted.

## Source policy

Family operations may use only canonical text/spans and the V2 metadata contained in their packet. No web, BOE, academy or external-knowledge source is part of the resolver contract.
